# DataDevQuest
Tableau Metadata API GraphQL Challenge
This repository demonstrates how to use the Tableau Metadata API with GraphQL to retrieve detailed information about published data sources and the workbooks connected to them.

**Challenge Overview**
https://datadevquest.com/ddq2025-07-tableau-metadata-api-intermediate/ 
This example was created as part of an intermediate Tableau Metadata API exercise. The challenge is to write a GraphQL query that fetches:
-  The details of a workbook or published datasource of your choice
-  The IDs, names, and project names for these resources
-  The owner's information (ID and name)
-  The connected downstream workbooks and the projects they belong to
With the Tableau Metadata API, tasks that require multiple REST API calls can be accomplished in a single GraphQL query.

https://help.tableau.com/current/api/metadata_api/en-us/index.html
